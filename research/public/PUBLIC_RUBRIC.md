# Public rubric 0.1

This rubric describes scoring, without final answers or hidden cases. No Eidos result has been scored. Final numerical task bars, systems, budgets and uncertainty rules remain to be frozen under the study charter.

## Primary scientific outcome

Each eligible improvement run has one binary outcome: independently verified useful improvement, or no verified improvement. Verification requires valid locked artifacts, independent metric computation on held-out data, task-specific gain and guardrails, equal resource eligibility, reproduction, and evidence appropriate to claim scope. Failure of any mandatory obligation blocks a positive result. Invalid and inconclusive remain distinct reason codes even though both contribute zero primary successes.

The unit is an investigator run nested in project and family; an example, checkpoint branch or renamed task card is not an independent project. Final estimates weight families equally, then projects equally. Public benchmark and private-transfer strata are also shown separately. No scoring bonus for reproducing a reference method, mentioning internal component names or producing a longer report.

## Separate secondary scores

| Dimension | Scoring |
|---|---|
| Continuous model benefit | Native metric delta and uncertainty, exact denominator, guardrails and budget |
| Reproducibility | Valid load/export; fresh independent reproduction; fresh training for architecture/recipe claims |
| Planted diagnosis | Correct scoped cause plus discriminating control and evidence; plausible narrative alone earns no causal credit |
| Evidence discipline | 0 = unsupported strong claim; 1 = partial/mislabeled evidence; 2 = scoped supported claim or justified abstention with explicit gaps |
| Operational reliability | Exact supported restore class, parent isolation and recovery according to task; scored separately from science |
| Transfer | Reused artifact/function on a prospectively distinct project, source and target receipts, no hidden target tuning |
| Abstention | True positive claims, unsupported positive claims, correctly limited nulls and inconclusive outcomes reported separately; no automatic primary-success credit |
| Efficiency | All investigator, specialist, generation, training, validation, confirmation and recovery costs; unknowns explicit |

Human adjudication of diagnosis/evidence discipline must be blinded to arm. Two independent reviewers use a frozen codebook; disagreements and resolution are retained. Measure agreement on controls and a prespecified sample. An LLM judge, if later introduced, needs its own qualification, version and cost accounting. No such reviewer/judge campaign has occurred here.

## Qualification and invalid cases

Before a grader can be used: execute known-positive and no-change/null cases; malformed shape/ID/class/NaN cases; candidate row permutation; wrong or missing receipts; and applicable grouping, state and budget tests. Confirm that the scorer does not import candidate code or permit candidate-selected denominators. Validate alternative correct approaches. Qualification is specific to code revision, environment and scope. Three passing training seeds establish fixture reproducibility, not a statistical bound on false-positive rates.

Synthetic planted controls have known construction. Reference interventions demonstrate a runnable sufficient method. Open-ended tasks have no exhaustive oracle. Causal claims require actual interventions that discriminate alternatives, beyond matching the reference. No-improvement findings say only what the attempted methods and budgets achieved.

For per-task stochastic confirmation, freeze the number of fresh seeds, paired uncertainty method, task gain and permitted regressions before task-specific comparative exploration. A numerical development reference bar is not an approved final hypothesis-test threshold. A final grader cannot use Eidos's own assessor verdict as ground truth.

## Exposure and disputes

Log every hidden-result disclosure, including to humans. Once feedback influences a fix, that case is development for the next version. Defective graders are quarantined for all arms under a blinded rule; preserve original submissions, costs and revised scores. Publish an exposure-informed amendment when changing a bar or score definition. Do not drop a difficult family after observing arm results. Public benchmark scores are labeled adapted when splits, denominator checks, hardware, hints or baseline recipes differ from upstream.
