# Pilot 3 fixed prospective procedure

Fixed on 2026-11-11, before executing any reference or investigator arm. Starting
Eidos commit: 7e6641d9f91a9adfd30b15e2c821ce25e5eb11a4.

Only the following four offline scikit-learn datasets will be considered, in order:

* N01: `load_breast_cancer()`, binary accuracy.
* N02: `load_diabetes()` (dataset defaults, including its intrinsic representation), RMSE.
* N03: `make_friedman1(n_samples=2000, noise=1.0, random_state=20261111)`, RMSE.
* N04: `make_classification(n_samples=3000, n_features=20, n_informative=8,
  n_redundant=4, n_clusters_per_class=3, class_sep=0.8, flip_y=0.02,
  random_state=20261111)`, accuracy.

Cast x to float32; y to int64 for classification or float32 for regression. IDs
are original row indices. Split indices with sklearn `train_test_split` twice:
first retain 60% train and 40% remainder (`test_size=0.4`), then divide the
remainder equally into validation and test (`test_size=0.5`). Both use
`random_state=20261111`; stratify both classification splits on their labels.
Rounding follows sklearn. No test arrays or generators enter investigator bundles.

The supplied baseline is a single PyTorch Linear layer, 2 logits for classification
or 1 output for regression; cross entropy or MSE; raw supplied features, no
scaling, preprocessing or engineering; full-batch Adam, learning rate 0.01,
80 epochs; CPU, one thread. The comparator is always seed 11. Classification
bar = 0.02 absolute accuracy. Regression bar = 0.05 times baseline seed-11 test
RMSE, stored at full precision as an absolute RMSE reduction. Train baseline
seeds 23 and 37 as additional diagnostics; do not change the comparator.

The one fixed reference per card is implemented in `reference_p3.py`:

* N01 and N04: train-only StandardScaler followed by SVC(C=10, kernel='rbf',
  gamma='scale', random_state=training seed); all other sklearn defaults.
* N02: train-only StandardScaler followed by Ridge(alpha=10); other defaults.
* N03: HistGradientBoostingRegressor(max_iter=200, max_leaf_nodes=15,
  learning_rate=0.1, l2_regularization=1, early_stopping=False,
  random_state=training seed); other defaults; raw supplied features.

Run each reference exactly once at each of seeds 11, 23 and 37 against the fixed
seed-11 baseline. Record every metric, gain, bar, split hash and runtime. Drop
any card whose reference misses its bar at any seed. Do not tune, replace, rerun
with different parameters, or add replacement cards. A failed reference is a
qualification result, never a reason to revise this procedure.

Runtime pins: CPython 3.12.8, torch 2.15.0, numpy 2.5.4, scikit-learn 1.9.1,
scipy 1.18.1 (the existing read-only research environment / public lock).
Dataset generation, baseline training and reference fitting run with network
denied. Git/GitHub operations are separate controller actions. No model calls.

After qualification, commit all accepted cards, numeric bars and bundles before
the first arm run (including infrastructure stubs). Reuse the pilot-2 packaging,
success, reproduction, charter, transport and analysis mechanisms. The immutable
public development tree is not edited. Grader labels are regenerated by trusted
pinned code in its separate score job. Hosted qualification covers N01 and N03
with reference, claimed-baseline and invalid-output controls.
