# ADR 0039 — Recover local decision bounds within the current phase

Status: Accepted for the prospective runtime.

A decision can hit its own request or wall limit with investigation budget still available. Ending the turn and entering autonomous conclude-only recovery on the first such result can skip ordinary reproduction and export. The independent review reproduced this transition with a bounded runtime result before the exploration deadline.

A local runtime outcome occupies its existing slot and is recorded separately from authored decisions. The next existing slot sees the outcome code without receiving the rejected raw reply. Consecutive local bounds share the existing refusal limit and finite fresh-turn retry policy. Accepted decisions still reset the consecutive counter. The activity distinguishes an independent per-decision limit from a deadline clipped to an authoritative phase boundary. At the exploration boundary, or on durable exploration token holdback, the ordinary finalization phase can use the existing reserve. Global budget, wall and turn limits still govern admission. The phase guard checks each job effect’s effective purpose, including the default on a direct run and the locked purpose of a planned trial. Previously a reproduction headline could pass the guard while an omitted direct-run purpose defaulted to open search. A finalization headline cannot authorize a challenger. For an ordinary direct reproduction the investigator must explicitly set the effect’s purpose. A planned launch uses the purpose already stored in its plan, and the refusal names the source of the effective purpose. Scoring a pending challenger remains possible under the existing input-lineage exception. A reproduction label alone does not establish that a run reproduced the incumbent. A conclude-only turn does not gain another logical slot.

Temporal patch markers retain the prior routing for histories that already recorded it. The change does not extend request, token or wall ceilings or reclassify provider failures. Scripted coordinator cases distinguish a single local bound, repeated local bounds and phase-clipped deadlines. A loopback fixture exercises durable runtime feedback and acceptance through real runtime and coordinator activities.


Ordinary finalization freezes candidate identity, including the absence of a lock. Pending work can finish and be scored, and reproduction can run under the existing controls. Its score cannot replace the frozen incumbent, regardless of declared job purpose. An exact reaffirmation returns the original lock ID, digest and version without writing a new candidate lock. A compatible reaffirmation may omit the original embedded selection rule because the immutable rule and metadata are retained. A lock note that names no job is refused during ordinary finalization so it cannot mask the existing lock. Changes to its evidence, scope, claim or other authored metadata are refused; separate observations can be ordinary notes. This deliberately also excludes late promotion of an earlier pending challenger. The rule protects selection; purpose labels alone cannot prevent all post-boundary compute.

When the ordinary token envelope does not fit the remaining positive investigation budget, autonomous recovery may use the existing reduced conclusion envelope. A late ordinary reservation refusal is typed before any provider request, and no extra quota or turns are granted. Global exhaustion still refuses admission. The phase schedule-to-close limit is distinct from an activity's shorter independent timeout. When Temporal declines a retry that would cross the phase-owned schedule limit, the workflow uses the phase boundary path. A start-to-close or heartbeat timeout before that boundary stays a failed activity. Workflow patch markers retain historical replay behavior.
